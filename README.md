# claude-skills-id

Kumpulan **skill Claude** berbahasa Indonesia untuk pekerjaan dokumen, laporan, dan presentasi.

## Isi
| Skill | Fungsi |
|---|---|
| `ringkas-dokumen` | Ringkasan eksekutif dari dokumen panjang |
| `laporan-mingguan` | Catatan mentah → laporan mingguan |
| `outline-presentasi` | Kerangka slide dari topik |

## Cara pakai
1. Zip folder skill yang diinginkan (mis. `skills/ringkas-dokumen`).
2. Di Claude: **Settings → Capabilities → Skills → Upload skill**.
3. Minta Claude seperti biasa; skill aktif otomatis sesuai `description`.

## Kontribusi
Tambahkan folder baru di `skills/<nama>/SKILL.md` dengan frontmatter `name` dan `description`.
