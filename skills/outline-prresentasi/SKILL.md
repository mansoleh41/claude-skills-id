# Outline Presentasi

1. Tanyakan/tetapkan: audiens, durasi, tujuan (informasi/ajakan/keputusan).
2. Hitung jumlah slide ≈ durasi menit ÷ 2.
3. Output per slide: **judul berupa kalimat pesan**, 3 poin maksimal, saran visual.
4. Alur: Masalah → Data → Solusi → Langkah berikutnya.
5. Akhiri dengan 1 slide ajakan bertindak.
